Faster than Darkness

A first person parkour endless runner built in one week, with sliding, wall running and grappling.

  • Unity
  • Movement systems
  • Game jam

This project was a 1-week game jam based on the theme "Faster than...". It's a parkour endless runner where the player tries to escape the darkness chasing them, focused on first person movement and quick reactions. The player can slide, wall run and grapple, which allows for some challenging obstacles.

My role was to create the first person character controller and all the extra movement that came with it, as well as a few obstacles for the course. It was my first first person controller, and the starting point for the later Modular First Person Controller.
