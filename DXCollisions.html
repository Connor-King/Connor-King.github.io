Collision & Response System in DirectX 11

A physics, collision detection and response system written from scratch in C++/DirectX 11, with AABB, OBB, sphere and ray tests and a quadtree broad phase.

  • C++
  • DirectX 11
  • Physics
  • Spatial partitioning

A physics, collision detection and response system written from scratch in C++ on DirectX 11, built to understand how collision works inside games and game engines rather than relying on one.

How it works

  • Collision primitives. Axis-aligned bounding boxes, oriented bounding boxes, spheres and raycasts, with intersection tests between them.
  • Broad phase. A quadtree partitions the scene so only nearby objects are tested against each other, substantially reducing the cost of collision checks.
  • Response and materials. Collisions drive a physics response, with materials per surface: the smaller platforms use a bouncier material that acts as a trampoline.
  • Test scene. A first person character controller jumping between platforms exercises the whole system end to end.
