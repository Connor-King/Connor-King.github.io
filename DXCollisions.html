Collision & Response System in DirectX 11

A physics, collision and response system built from scratch in C++ and DirectX 11, with quadtree broad-phase.

  • C++
  • DirectX 11
  • Physics
  • Spatial partitioning

For this project I looked at how collision systems work within games and game engines, then created my own physics, collision and response system in DirectX 11 using C++. The project includes a first person character controller which the user controls to jump from one platform to another. The smaller platforms have a bouncier material which acts like a trampoline.

The collision system supports several physics objects:

  • Axis-aligned bounding boxes
  • Oriented bounding boxes
  • Spheres
  • Raycasts

Using these objects, I implemented different methods for detecting collisions between them. To speed up collision detection, I built a quadtree, which lets the system check for collisions only between nearby objects, substantially reducing the time collision checks take.

Tech
