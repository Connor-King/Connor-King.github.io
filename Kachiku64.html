Kachiku 64

A 64-player local multiplayer game where phones become controllers through a locally hosted web page. Built by a 34-person cohort.

  • Unity
  • Web controllers
  • Networking
  • 34-person team

Kachiku 64 is a 64-player local multiplayer game made with Unity. It was a cohort project (34 people) during the final year of my undergraduate degree: a multiplayer mayhem game where everyone fights to be the last character standing.

The game uses a lot of old-school game mechanics in fun ways. My role was to build the system that let players easily join and control a character using their phone. We didn't want it to be app-based, as that would make joining harder, so we used a locally hosted website that acts as a controller when someone connects to it.

The 34 developers were split into 6 teams, each with a tech lead and a design lead. The leads were responsible for agreeing with other teams how mechanics and features would be implemented, to prevent conflicts. It was a great way to learn new technologies and work with a large group.
