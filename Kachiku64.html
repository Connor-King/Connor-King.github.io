Kachiku 64

A 64-player local multiplayer game where any phone becomes a controller through a locally hosted web page, with no app to install. Built by a 34-person cohort.

  • Unity
  • Web controllers
  • Networking
  • 34-person team

A 64-player local multiplayer game built in Unity by a cohort of 34 developers in the final year of my undergraduate degree. Everyone fights to be the last character standing, in a game built from old-school mechanics.

My contribution: phones as controllers

I built the system that lets players join and control a character from their own phone. An app would have made joining harder, so instead the game uses a locally hosted website that acts as a controller when a phone connects to it.

Working at scale

The 34 developers were split into 6 teams, each with a tech lead and a design lead. The leads agreed with other teams how mechanics and features would be implemented, to prevent conflicts between teams' work.
