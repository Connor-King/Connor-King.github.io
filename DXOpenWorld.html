Open World Sandbox in C++ & DirectX 11

An endless, modifiable voxel world using value noise generation, multithreaded chunk streaming and quadtree-accelerated collision.

  • C++
  • DirectX 11
  • Multithreading
  • Procedural generation

For this project I explored the use of multithreading, value noise and a quadtree to create an endless interactive world. The world is generated using value noise, which gives the terrain its organic feel. The project was written in C++ using the DirectX 11 framework.

The world is generated in chunks of 64 by 64. Each chunk is loaded in using multithreading. If a chunk is modified in any way, it is saved to an XML file, so the player can modify the world and have it stay that way.

The player controls a first person character which they can use to explore and modify the world. The controller uses raycasts to detect a cube for destruction, and to detect a cube's face and normal when placing a cube. The player can collide with and modify the world thanks to a quadtree that accelerates collision detection; without it, the frame rate would drop too low to be playable.

Tech
C++, DirectX 11
Focus
