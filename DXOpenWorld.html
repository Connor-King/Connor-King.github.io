Open World Sandbox in C++ & DirectX 11

An infinite, editable voxel world in C++/DirectX 11: value-noise terrain, chunks loaded on separate threads, and quadtree-accelerated collision.

  • C++
  • DirectX 11
  • Multithreading
  • Procedural generation

An infinite voxel sandbox written in C++ on DirectX 11. It tackles three problems that sit underneath any large real-time world: generating terrain procedurally, loading it as the player moves, and keeping collision cheap as the world grows.

How it works

  • Procedural terrain. Terrain is generated from value noise, which gives it an organic shape with no hand-authored content.
  • Chunk streaming. The world is split into 64×64 chunks, each loaded using multithreading so chunk loading runs off the main thread.
  • Persistence. Any chunk the player modifies is saved to XML and reloaded later, so edits survive the chunk being unloaded and loaded again.
  • Interaction. Raycasts against the voxel grid pick the cube to destroy, and return the hit face and normal so new cubes are placed on the correct side.
  • Collision. A quadtree limits collision tests to nearby geometry. Without it, the frame rate dropped too low to be playable.
