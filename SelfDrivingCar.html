Self-Driving Car with Machine Learning

A convolutional neural network, trained in Python and TensorFlow, that drives a car in Unity from camera frames alone while avoiding other cars.

  • Unity
  • Python
  • TensorFlow
  • CNN

This project was my first experience of using machine learning to build something. I created a self-driving car within Unity using Python and TensorFlow. The catch: the only input to the neural network is the image from the front of the car.

The system is a convolutional neural network which analyses each frame to decide whether to drive forward, turn left or turn right. To train the network, I drove around a random track for 2 hours. While I drove, a Python program captured the view from the front of the car along with my input (left, right or forward) for that frame. This was the data I used to train the network.

After training, the car could complete a full lap of the track while avoiding the other stationary cars. It could also drive a randomly generated track (completing it, or running for a good while), showing good generalisation.

Tech
Unity, Python, TensorFlow
Focus
Convolutional neural networks, data capture, generalisation
