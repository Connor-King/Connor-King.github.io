Self-Driving Car with Machine Learning

A convolutional neural network, trained in Python/TensorFlow on recorded human driving, that steers a car in Unity using only its front camera.

  • Unity
  • Python
  • TensorFlow
  • CNN

A self-driving car in Unity, controlled by a convolutional neural network built in Python and TensorFlow. The constraint: the network's only input is the image from the front of the car.

How it works

  • Data capture. I drove around a random track for 2 hours while a Python tool recorded each frame from the car's camera alongside my input for that frame (left, right or forward).
  • Model. The CNN is trained on those labelled frames to classify each new frame into one of the three actions, learning to imitate a human driver.
  • Control loop. At runtime, each camera frame is passed through the network and the predicted action drives the car.

Results

After training, the car completed a full lap of the track while avoiding stationary cars. It could also drive randomly generated tracks it hadn't been trained on, either completing them or running for a good while, showing the model had generalised rather than memorised one track.
