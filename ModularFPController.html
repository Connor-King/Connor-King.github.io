Modular First Person Controller

A component-based first person controller in Unity with advanced movement: sliding, grappling, mantling, wall running, zip lines and more.

  • Unity
  • C#
  • Component architecture
  • Movement systems

For this project I explored using a component-based system to create a first person controller with advanced movement mechanics in Unity.

The controller is built from modular components which can be added to or removed from the main controller without affecting how it works. Most components need no specific objects in the scene (only the zip line and pole swinging do), so the controller works in most environments without setup.

The components include:

  • Sliding
  • Grappling (pull towards an object, or swing)
  • Mantling (step up and climb)
  • Ledge grabbing
  • Wall running (vertical and horizontal)
  • Zip lines
  • Pole swinging
Tech
Unity, C#
Focus
Component-based architecture, character movement
