Modular First Person Controller

A component-based first person controller in Unity: each movement ability is a self-contained module that can be added or removed without touching the core controller.

  • Unity
  • C#
  • Component architecture
  • Movement systems

An advanced first person controller for Unity, built around a component-based architecture so movement abilities can be mixed and matched per project.

Design

  • Modular abilities. Each mechanic is a separate component that can be added to or removed from the core controller without changing how the controller works.
  • Minimal scene setup. Most abilities need no special objects in the level. Only zip lines and pole swinging do, so the controller works in most environments without setup.

Abilities

  • Sliding
  • Grappling (pull towards an object, or swing)
  • Mantling (step up and climb)
  • Ledge grabbing
  • Wall running (vertical and horizontal)
  • Zip lines
  • Pole swinging
Tech
Unity, C#
Focus
Component-based architecture, character movement
