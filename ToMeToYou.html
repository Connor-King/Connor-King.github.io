To Me To You

A networked two-player co-operative VR game for the Oculus Quest, built with Unity and Photon PUN.

  • Unity
  • VR
  • Oculus Quest
  • Photon PUN

For this project, we explored using the Oculus Quest to create a fun, multiplayer co-operative VR experience.

The game is centred on controlling a minecart through various levels and navigating obstacles. It uses Photon PUN for Unity and supports two players in each lobby.

I worked on the networking for the game and built VR interactions with some of the objects. I also created the character controllers and produced some of the levels.

Tech
Unity, Photon PUN
Platform
Oculus Quest
My role
Networking, VR interactions, character controllers, level design
