3D Environments From Real-World Data

Builds a playable 3D environment in real time from the device's GPS position, using OpenStreetMap buildings and roads plus weather and local time. Runs on mobile and PC.

  • Unity
  • OpenStreetMap
  • Procedural meshes
  • Mobile

A Unity system that turns real-world location data into a playable 3D environment at runtime: take external data you don't control, and build a usable scene from it on the fly.

Pipeline

  1. Locate. Read the device's GPS position.
  2. Fetch. Request map data for that location from the OpenStreetMap API, along with weather data and local time.
  3. Parse. Group the returned map data into objects such as buildings and roads.
  4. Build. Generate a mesh for each object at runtime and place it at its matching position in the scene.
  5. React. Change the environment dynamically based on real-world variables such as the weather.

The system is lightweight enough to run on a mobile device, but flexible enough to be customised for a complex 3D application. It runs on both mobile and PC, and builds environments wherever map data is available.

Tech
Unity, C#, OpenStreetMap API
Platforms
Mobile and PC
Focus
Real-world data, runtime mesh generation
