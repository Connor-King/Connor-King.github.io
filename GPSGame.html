3D Environments From Real-World Data

Streams OpenStreetMap, weather and time data for the device's GPS location and builds a playable 3D environment in real time, on mobile and PC.

  • Unity
  • OpenStreetMap
  • Procedural meshes
  • Mobile

This project investigates creating a 3D game environment from real-world map data in Unity. It gathers multiple data types, including weather, buildings, roads and local time, and builds a playable 3D environment in real time, using that data to change the environment dynamically. It is lightweight enough to run on a mobile device, but flexible enough to be customised for a complex 3D application.

The system first gets the device's GPS location, then requests the map data for that location from the OpenStreetMap API. The data is parsed to group the objects, and a mesh is created for each object and placed in the matching location in the scene.

The project works on both mobile and PC. It successfully builds 3D environments from the map data where that data is available, and changes the environment based on other real-world variables such as the weather.

Tech
Unity, C#, OpenStreetMap API
Platforms
Mobile and PC
Focus
Real-world data, runtime mesh generation
